# Spellingcorrecties van Urker liedteksten

Alle 16 .md-bestanden zijn gecontroleerd. De bestaande bestandsnamen, YAML-frontmatter,
Nederlandstalige toelichtingen, liedindeling en regelafbrekingen zijn behouden.
Alleen de spelling in de liedteksten na `## Tekst` is aangepast.

**Toegepaste regels**

- `leeven` → `leven`; `bleeven` → `bleven`; `kreeten` → `kreten`;
  analoog `weezen` → `wezen`.
- `oa` → `ao`, met de specifiekere regel `oan` en `aon` → `oon` eerst.
- Begin-h vervalt in Urker liedtekstwoorden wanneer deze in het Nederlands als h wordt uitgesproken
  (zoals `hert` → `ert`, `hij` → `ij`). Afkortingen zoals HAVO blijven behouden.
- Invoeging van sjwa tussen liquida en een niet-coronale medeklinker verdwijnt
  alleen in evidente gevallen, zoals `karrek` → `kark`, `mellek` → `melk`,
  `arreg` → `arg`, `zurreg` → `zurg`, `volleges` → `volges`,
  `alleve` → `alve`, `muuleker` → `muulker`.
  De regel wordt niet mechanisch toegepast op woorden met een lexicale klinker
  zoals `lekker`, `allemaal` en `eagenlek`.

Dit is een **minimale spellingcorrectie** en geen herschrijving van de teksten.
De twee CSV-bestanden geven per regel respectievelijk per woord alle veranderingen weer.
