# vursiesvanjan.nl

Liedjes in het Urker dialect, geschreven, vertaald en hertaald door Jan Bakker.

Statische site op basis van [Astro](https://astro.build), automatisch
gepubliceerd naar GitHub Pages bij elke push naar `main`.

- Een nieuw liedje toevoegen: zie **[HANDLEIDING.md](HANDLEIDING.md)**
- Lokaal bekijken: `npm install` en daarna `npm run dev`
